# Security policy

Please report a security problem in this action, or in the Converter Studio API it calls, by e-mail
to support@converter.studio rather than in a public issue. Describe what you found and how to
reproduce it.

Only the latest release of the action (the `v1` tag) gets fixes.

How the action handles your files and your API key is described in the README's
[Privacy and security](README.md#privacy-and-security) section and in Converter Studio's
[privacy policy](https://converter.studio/privacy).
